# 12_COPYWRITING_GUIDE

**Project:** ShrotiHost  
**Document Version:** 1.0  
**Status:** Draft

---

# Purpose

This document establishes the writing standards for every piece of public-facing content across the ShrotiHost platform.

The goal is to create a consistent voice that is clear, trustworthy, modern, and approachable.

---

# Brand Voice

ShrotiHost should always sound:

- Helpful
- Honest
- Professional
- Friendly
- Confident
- Knowledgeable

Never sound:

- Aggressive
- Pushy
- Overly technical
- Clickbait
- Misleading

---

# Writing Principles

1. Write for humans first.
2. Explain technical concepts simply.
3. Focus on outcomes, not jargon.
4. Keep paragraphs short.
5. Use active voice whenever possible.

---

# Messaging Priorities

Instead of:

"Unlimited NVMe SSD Hosting"

Prefer:

"Launch your website with fast, reliable hosting built for growth."

---

# Headlines

Headlines should be:

- Short
- Benefit-focused
- Memorable
- Easy to scan

Examples:

- Launch Faster.
- Hosting Made Simple.
- Build Without Limits.
- Start Your Next Project.

---

# Calls to Action

Preferred CTAs:

- Get Started
- Launch Now
- Compare Plans
- Talk to Hosting Advisor
- Explore Features
- Start Building

Avoid generic CTAs like:

- Click Here
- Submit

---

# Product Descriptions

Every product description should answer:

- Who is it for?
- Why should they choose it?
- What problem does it solve?
- How can they grow?

---

# Error Messages

Error messages should be:

- Clear
- Helpful
- Actionable

Example:

Instead of:
"Error 500"

Use:
"Something went wrong. Please try again in a moment or contact support if the problem continues."

---

# Success Messages

Celebrate customer progress.

Example:

"Your hosting account is ready. You're only a few minutes away from launching your website."

---

# AI Assistant Tone

The AI Assistant should:

- Educate
- Recommend
- Guide

Never pressure users into making purchases.

---

# SEO Writing

- Use descriptive headings.
- Write naturally.
- Avoid keyword stuffing.
- Prioritize readability.

---

# Accessibility

Use simple language where possible.

Avoid unexplained acronyms.

Use descriptive link text.

---

# Content Review Checklist

Before publishing, confirm:

- Grammar is correct.
- Tone matches the brand.
- Information is accurate.
- Customer benefits are clear.
- Calls to action are obvious.
