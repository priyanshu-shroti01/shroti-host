# 36_USER_ACCOUNT

**Project:** ShrotiHost  
**Document Version:** 1.0  
**Status:** Draft

---

# Purpose

This document defines the User Account experience for ShrotiHost. It covers profile management, security settings, notification preferences, connected services, and privacy controls.

---

# Primary Goals

- Make account management simple
- Improve account security
- Give users control over preferences
- Support self-service
- Maintain a consistent experience

---

# Target Audience

- Individual customers
- Students
- Businesses
- Agencies
- Startup teams

---

# Account Structure

1. Profile Overview
2. Personal Information
3. Security
4. Notification Preferences
5. Connected Services
6. Active Sessions
7. Privacy
8. Account Actions

---

# Profile

Users can update:

- Name
- Email
- Phone number
- Company
- Profile picture (future)

---

# Security

Support:

- Password changes
- Email verification
- Two-factor authentication (future)
- Recovery options
- Login history

---

# Notification Preferences

Allow users to control:

- Billing notifications
- Service alerts
- Maintenance notices
- Marketing emails
- Product updates

---

# Connected Services

Display linked services such as:

- Hosting accounts
- Domains
- Support
- Billing profile

Future integrations may include third-party logins.

---

# Active Sessions

Show:

- Current session
- Device list
- Login time
- IP/location (approximate)
- Sign out of other sessions

---

# Privacy

Users should be able to:

- Manage personal information
- Download account data (future)
- Request account deletion
- Review privacy settings

---

# Accessibility

Support:

- Keyboard navigation
- Screen readers
- Responsive layouts
- WCAG AA compliance

---

# Analytics

Track:

- Profile updates
- Password changes
- Notification preference changes
- Session revocations

---

# Success Metrics

- Increased account security
- Reduced support requests
- Higher user engagement
- Faster profile updates

---

# Acceptance Checklist

The User Account page should:

- Be easy to navigate
- Protect user data
- Support self-service
- Follow the ShrotiHost design system
