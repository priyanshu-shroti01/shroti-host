# 37_NOTIFICATION_SYSTEM

**Project:** ShrotiHost
**Document Version:** 1.0
**Status:** Draft

---

# Purpose

This document defines the Notification System for ShrotiHost. It covers all customer-facing notifications, including billing reminders, service updates, security alerts, maintenance notices, and marketing communications.

---

# Primary Goals

- Keep customers informed
- Deliver timely alerts
- Reduce missed renewals
- Improve security awareness
- Give users full notification control

---

# Target Audience

- Individual customers
- Students
- Businesses
- Agencies
- Startup teams

---

# Notification Channels

Supported channels:

- In-app notifications
- Email notifications

Future channels:

- SMS
- Push notifications
- WhatsApp
- Mobile app notifications

---

# Notification Center

The Notification Center should display:

- Unread notifications
- Recent notifications
- Archived notifications
- Notification categories
- Mark as read/unread
- Clear history (optional)

---

# Notification Categories

- Billing
- Renewals
- Hosting
- Domains
- Support
- Security
- Maintenance
- Product Updates
- Promotions

---

# Billing Notifications

Examples:

- Invoice generated

- Upcoming renewal
- Subscription expired

---

# Hosting Notifications

Examples:

- Service activated
- Upgrade completed
- Resource usage warning
- Backup completed
- Service suspended

# Domain Notifications

Examples:

- Domain expiry reminder
- Transfer completed
- DNS updated
- WHOIS changes
- Auto-renew reminder

# Security Notifications

Examples:

- Account verification
- Security recommendations
