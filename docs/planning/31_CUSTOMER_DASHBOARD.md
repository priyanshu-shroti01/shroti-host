# 31_CUSTOMER_DASHBOARD

**Project:** ShrotiHost
**Document Version:** 1.0
**Status:** Draft

---

# Purpose

This document defines the Customer Dashboard experience. It serves as the central workspace where customers manage hosting services, domains, billing, support, and account settings.

---

# Primary Goals

- Provide a clear overview of services
- Simplify common management tasks
- Surface important notifications
- Reduce support requests through self-service
- Deliver a fast and responsive experience

---

# Target Audience

- Individual customers
- Students
- Freelancers
- Small businesses
- Startup teams
- Agencies

---

# Dashboard Structure

1. Top Navigation
2. Sidebar Navigation
3. Account Overview
4. Quick Actions
5. Hosting Services
6. Domains
7. Billing
8. Support
9. Notifications
10. Footer (optional)

---

# Overview Widgets

Display:

- Active Hosting Plans
- Active Domains
- Upcoming Renewals
- Recent Invoices
- Support Ticket Status
- Resource Usage

---

# Quick Actions

Provide shortcuts for:

- Launch cPanel
- Open File Manager
- Manage DNS
- Renew Service
- Create Support Ticket
- Order New Hosting

---

# Hosting Management

Allow users to:

- View hosting plans
- Check resource usage
- Access control panel
- Restart services (future)
- Upgrade plans

---

# Domain Management

Features:

- View domains
- Manage nameservers
- DNS records
- WHOIS details
- Auto-renew settings
- Domain lock

---

# Billing

Include:

- Invoice history
- Payment methods
- Upcoming renewals
- Download invoices
- Transaction history

---

# Support

Users should be able to:

- Create tickets
- View ticket status
- Reply to tickets
- Access knowledge base
- View maintenance notices

---

# Notifications

Examples:

- Service renewals
- Payment reminders
- Security notices
- Planned maintenance
- Product announcements

---

# Search

Global search should help users quickly find:

- Services
- Domains
- Invoices
- Support tickets
- Documentation

---

# User Settings

Allow customers to update:

- Profile
- Password
- Two-factor authentication (future)
- Notification preferences

---

# Accessibility

Support:

- Keyboard navigation
- Screen readers
- Responsive layouts
- WCAG AA compliance

---

# Performance

Dashboard should:

- Load quickly
- Use lazy loading where appropriate
- Cache non-critical data
- Minimize API requests

---

# Analytics

Track:

- Login frequency
- Dashboard usage
- Quick action clicks
- Support interactions
- Renewal conversions

---

# Success Metrics

- Faster task completion
- Lower support volume
- Higher customer satisfaction
- Improved renewal rates

---

# Acceptance Checklist

The dashboard should:

- Be easy to navigate
- Provide useful summaries
- Support self-service
- Perform well on all devices
- Follow the ShrotiHost design system
