# 18_ILLUSTRATION_GUIDE

**Project:** ShrotiHost  
**Document Version:** 1.0  
**Status:** Draft

---

# Purpose

This document defines the illustration language for ShrotiHost. Illustrations should strengthen the brand, simplify technical concepts, and create a premium visual experience.

The illustration system must remain consistent across the marketing website, documentation, customer dashboard, blog, and future applications.

---

# Illustration Philosophy

Illustrations should:

- Explain ideas visually
- Inspire confidence
- Feel modern
- Support storytelling
- Never distract from content

Every illustration should have a functional purpose.

---

# Visual Style

The preferred illustration style is:

- Futuristic
- Minimal
- Premium
- Technology-inspired
- Clean geometric forms
- Soft gradients
- Subtle glow effects

Avoid cartoon-style illustrations.

---

# AI Generated Artwork

AI-generated artwork may be used if it follows the brand identity.

Requirements:

- Consistent lighting
- Consistent perspective
- Premium appearance
- High resolution
- No visual artifacts
- No watermarks

---

# 3D Illustration Direction

Preferred 3D subjects:

- Cloud infrastructure
- Server clusters
- Data centers
- AI core
- Network connections
- Security shields
- Performance graphs

3D elements should appear polished and realistic.

---

# Color Harmony

Illustrations must follow the official color system.

Use:

- Brand accent colors
- Neutral backgrounds
- Soft gradients
- Controlled highlights

Avoid random color palettes.

---

# Lighting Style

Lighting should be:

- Soft
- Cinematic
- Directional
- Consistent

Preferred effects:

- Ambient glow
- Rim lighting
- Glass reflections

Avoid harsh shadows.

---

# Composition

Illustrations should:

- Leave space for text
- Scale well across devices
- Maintain visual balance
- Guide user attention

---

# Homepage Artwork

Hero section artwork should communicate:

- Innovation
- Performance
- Intelligence
- Reliability

Without overwhelming the headline.

---

# Product Illustrations

Each product should have a unique illustration while sharing the same visual language.

Examples:

- Shared Hosting
- WordPress Hosting
- Unlimited Hosting
- Domains
- Student Program
- Startup Program

---

# Background Graphics

Background graphics should remain subtle.

Use:

- Abstract geometry
- Soft gradients
- Particle effects
- Grid patterns

Avoid noisy backgrounds.

---

# Animation Compatibility

Illustrations should support:

- Floating motion
- Gentle parallax
- Glow animations
- Hover interactions

Animations must remain smooth and lightweight.

---

# Accessibility

Illustrations must never replace essential information.

Important content should always be available as text.

---

# Asset Naming

Use descriptive filenames.

Example:

hero-ai-core.webp

student-program-illustration.webp

hosting-performance-3d.webp

---

# Export Standards

Preferred formats:

- SVG (vector)
- WebP
- AVIF
- PNG (only when transparency is required)

Optimize every asset for web performance.

---

# Acceptance Checklist

Every illustration should:

- Match the brand
- Follow the color system
- Be optimized for the web
- Support responsive layouts
- Reinforce the message of the page

---

# Future Expansion

Future illustration categories:

- Customer Dashboard
- AI Assistant
- Voice Interface
- Cloud Platform
- Mobile Application
- Developer Tools
