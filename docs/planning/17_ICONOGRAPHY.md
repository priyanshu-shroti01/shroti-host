**Project:** ShrotiHost

# Purpose

This document defines the iconography system used throughout ShrotiHost. Icons should reinforce clarity, improve navigation, and maintain a consistent visual identity across all products.

---

# Icon Philosophy

Icons should be:

- Simple
- Recognizable
- Consistent
- Minimal
- Functional

Icons should support content, not replace it.

---

# Design Principles

- Consistent stroke width
- Rounded corners where appropriate
- Balanced proportions
- Pixel-perfect alignment
- SVG-first implementation

---

# Sizes

Recommended sizes:

- 16px
- 20px
- 24px
- 32px
- 48px
- 64px

Avoid arbitrary sizes.

---

# Color Usage

Icons should inherit semantic colors where possible.

Do not introduce decorative colors unless required by branding.

---

# Accessibility

Every meaningful icon must:

- Include an accessible label where needed
- Have sufficient contrast
- Never be the only indicator of important information

---

# Animation

Icons may animate only to:

- Confirm actions
- Indicate loading
- Highlight notifications
- Improve onboarding

Animations should remain subtle and purposeful.

---

# Do

- Use consistent sizing
- Align icons with text
- Maintain spacing
- Use SVG assets

# Don't

- Mix icon libraries
- Stretch icons
- Apply random colors
- Use decorative icons without purpose
