# Purpose

This document defines the Student Program page. The page should clearly communicate the benefits of the program, explain eligibility, simplify the application process, and encourage students to launch their first website with ShrotiHost.

- Lower the barrier to getting started
- Build long-term customer relationships
- Encourage portfolio and project hosting
- Increase student sign-ups
