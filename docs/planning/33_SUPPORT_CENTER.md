# 33_SUPPORT_CENTER

**Project:** ShrotiHost
**Document Version:** 1.0
**Status:** Draft

---

# Purpose

This document defines the Support Center experience for ShrotiHost. It provides customers with a centralized place to request help, track issues, access documentation, and stay informed about service status.

---

# Primary Goals

- Deliver fast, organized customer support
- Encourage self-service through documentation
- Reduce response times
- Improve customer satisfaction
- Integrate seamlessly with WHMCS

---

# Target Audience

- Hosting customers
- Domain customers
- Students
- Businesses
- Startup teams
- Agencies

---

# Support Center Structure

1. Support Dashboard
2. Create Ticket
3. Ticket History
4. Knowledge Base
5. Service Status
6. Maintenance Notices
7. AI Support Assistant (Future)
8. Contact Options

---

# Support Dashboard

Display:

- Open tickets
- Waiting for customer response
- Recently resolved tickets
- Recent announcements
- Service status summary

---

# Ticket Lifecycle

1. Customer creates ticket
2. Ticket assigned
3. Support response
4. Customer reply
5. Issue resolved
6. Customer confirmation
7. Ticket closed

---

# Ticket Categories

- Technical Support
- Billing
- Domains
- Website Migration
- Sales
- Abuse Report
- Feature Request
- Other

---

# Ticket Priority

Support priorities:

- Low
- Normal
- High
- Critical

Priority should guide response expectations.

---

# Knowledge Base

Provide searchable articles covering:

- Getting Started
- cPanel
- DNS
- Email
- WordPress
- Security
- Billing
- Troubleshooting

---

# Service Status

Show:

- Operational services
- Ongoing incidents

- Recent outages

---

# Contact Methods

Support options may include:

- Ticket system
- Email
- Live Chat (Future)
- AI Assistant (Future)

---

# Attachments

Support secure uploads for:

- Screenshots
- Log files
- PDFs
- ZIP archives

Apply size and file-type validation.

# Customer Feedback

After ticket resolution, allow customers to rate:

- Response speed
- Helpfulness
- Overall satisfaction

# Accessibility

Support:

- Keyboard navigation
- Screen readers

- WCAG AA compliance

---

# Analytics

Track:

- Ticket volume
- Average response time

- Customer satisfaction
- Knowledge base usage

# Success Metrics

- Faster resolutions
- Reduced repeat tickets
- Higher satisfaction scores
- Increased self-service adoption

# Acceptance Checklist

The Support Center should:

- Make it easy to request help
