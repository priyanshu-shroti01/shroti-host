# 02_BRAND_GUIDELINES

**Project:** ShrotiHost  
**Document Version:** 1.0  
**Status:** Draft

---

# Purpose

This document defines the complete visual identity of ShrotiHost. Every interface, illustration, animation, advertisement, document, and future product must follow these guidelines.

---

# Brand Personality

ShrotiHost should always feel:

- Premium
- Modern
- Trustworthy
- Intelligent
- Developer Friendly
- Innovative
- Approachable

Avoid appearing:

- Cheap
- Generic
- Corporate
- Outdated
- Overly flashy

---

# Brand Positioning

ShrotiHost is an affordable premium hosting platform focused on students, developers, startups, creators, and growing businesses.

---

# Logo Usage

Use only the official ShrotiHost logo.

### Dark Background
Use the light version of the logo.

### Light Background
Use the dark version of the logo.

Never:
- Stretch the logo
- Rotate the logo
- Add shadows
- Change colors
- Modify proportions

Maintain clear space equal to the height of the cloud icon around all sides.

---

# Color Philosophy

Colors should communicate confidence rather than excitement.

Accent colors are used sparingly.

Large areas should remain clean and minimal.

---

# Primary Palette

Primary Background:
Near Black

Secondary Background:
Dark Graphite

Primary Accent:
Brand Purple

Secondary Accent:
Electric Blue

Success:
Emerald Green

Warning:
Amber

Error:
Soft Red

---

# Light Theme

Background:
Pure White

Surface:
Light Gray

Cards:
White

Primary Accent:
Brand Purple

---

# Typography

Headings:
Modern geometric sans-serif.

Body:
Highly readable sans-serif.

Guidelines:

- Large headings
- Comfortable line height
- Consistent spacing
- Maximum readability

---

# Iconography

Icons should be:

- Simple
- Rounded corners
- Consistent stroke width
- Minimal detail
- SVG only

Avoid inconsistent icon packs.

---

# Illustration Style

Illustrations should be:

- AI generated
- Futuristic
- Minimal
- Isometric where appropriate
- Consistent lighting
- Purple/blue accent lighting

Never use generic stock illustrations.

---

# 3D Direction

3D is reserved for premium sections.

Approved uses:

- Hero AI Core
- Floating server objects
- Infrastructure visualization
- Network globe

Avoid decorative 3D with no purpose.

---

# Motion Guidelines

Animations should feel smooth and intentional.

Recommended duration:

150–400 ms

Hover effects should enhance usability.

Avoid excessive motion.

---

# Spacing System

Use an 8px spacing scale throughout the project.

Maintain generous whitespace.

---

# Buttons

Primary:
Filled brand accent.

Secondary:
Outline.

Ghost:
Transparent.

Buttons should have subtle hover elevation and smooth transitions.

---

# Cards

Rounded corners.

Soft shadows.

Glass surfaces only where appropriate.

No heavy borders.

---

# Photography

Avoid stock office photos.

Use:

- Product visuals
- Infrastructure concepts
- Developer environments
- AI-inspired graphics

---

# Brand Voice

Writing should be:

- Helpful
- Honest
- Clear
- Professional
- Friendly

Avoid exaggerated marketing language.

---

# Accessibility

Maintain strong color contrast.

Readable typography.

Keyboard accessibility.

Clear focus states.

---

# Consistency Rules

Every new component must follow:

- Same spacing
- Same typography
- Same motion
- Same border radius
- Same color system

Consistency is more important than visual variety.

---

# Future Evolution

The brand should evolve gradually while preserving recognition.

Never redesign the identity without updating this document.
