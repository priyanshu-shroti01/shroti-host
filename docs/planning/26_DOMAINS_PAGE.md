# Purpose

This document defines the structure, content, and user experience for the Domains page.

The page should help visitors search, compare, register, transfer, and manage domains while building confidence in ShrotiHost as a domain provider.

---

# Primary Goals

- Make domain search simple.
- Explain domain registration.
- Encourage domain purchases.
- Increase hosting + domain bundles.
- Educate first-time users.

- Freelancers
- Small Businesses
