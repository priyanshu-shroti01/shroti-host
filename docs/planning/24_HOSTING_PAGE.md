# Purpose

This document defines the structure, objectives, content hierarchy, and user experience for the Shared Cloud Hosting product page.

The page should educate visitors, build confidence, compare plans clearly, and guide users toward purchasing the most suitable hosting plan.

---

# Primary Goals

- Explain Shared Cloud Hosting.
- Help visitors compare plans.
- Showcase benefits over competitors.
- Build trust through transparency.
- Increase conversions.

---

# Target Audience

- Students
- Personal websites
- Bloggers
- Freelancers
- Small businesses
- Developers launching small projects

---

# Page Structure

1. Hero Section
2. Plan Comparison
3. Why Shared Hosting
4. Key Features
5. Infrastructure
6. Migration
7. Student Program
8. Frequently Asked Questions
9. Final Call-to-Action
10. Footer

---

# Hero Section

Headline:

Fast, Reliable Cloud Hosting for Every Project

Supporting text should explain simplicity, performance, and affordability.

Primary CTA:
Get Started

Secondary CTA:
Compare Plans

---

# Plan Comparison

Display:

- Launch
- Grow (Recommended)
- Scale

Allow visitors to switch between:

- Monthly
- Quarterly
- Semi-Annual
- Annual

Display savings for longer billing cycles.

Highlight:

- LiteSpeed Web Server
- CloudLinux
- Free SSL
- Daily Backups
- Free Website Migration
- Node.js Support
- Python Support
- Softaculous Installer
- Business Email
- Imunify360 Security

# Infrastructure

Explain:

- NVMe SSD Storage
- CloudLinux Isolation
