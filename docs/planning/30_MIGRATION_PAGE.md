# Purpose

This document defines the Website Migration page. The objective is to reassure prospective customers that moving their website to ShrotiHost is simple, secure, and supported by an experienced team.

---

# Primary Goals

- Reduce hesitation when switching providers
- Explain the migration process clearly
- Build trust through transparency
- Increase migration requests
- Convert visitors into hosting customers

# Migration Workflow

1. Submit migration request
2. Review website details
3. Schedule migration
4. Transfer files and databases
5. Verify website functionality
6. Update DNS (if required)
7. Confirm successful launch

---

# Timeline

Typical migration duration depends on website size and complexity.

Communicate expected timeframes and any planned maintenance windows.

---

# Pre-Migration Checklist

Customers should:

- Share hosting credentials
- Confirm domain ownership
- Create a backup (recommended)
- Notify of special configurations

---

# Post-Migration Verification

Verify:

- Website loading
- SSL certificate
- Email functionality
- Database connectivity
- Forms and integrations
- Performance
