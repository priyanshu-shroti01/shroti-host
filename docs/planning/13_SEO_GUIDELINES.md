# 13_SEO_GUIDELINES

**Project:** ShrotiHost
**Document Version:** 1.0
**Status:** Draft

---

# Purpose

This document defines the SEO standards for the ShrotiHost website to ensure long-term organic growth, discoverability, and excellent search performance.

---

# SEO Objectives

- Rank for relevant hosting keywords.
- Improve organic traffic.
- Build topical authority.
- Optimize for Core Web Vitals.
- Support future AI-powered search experiences.

---

# URL Structure

Use short, descriptive URLs.

Examples:

/
 /hosting
 /wordpress-hosting
 /unlimited-hosting
 /domains
 /student
 /startup
 /blog
 /docs
 /contact

Avoid unnecessary URL nesting.

---

# Metadata Standards

Every page must include:

- Unique title
- Meta description
- Canonical URL
- Open Graph tags
- Twitter Card tags

Titles should be under 60 characters.

Descriptions should be 140–160 characters.

---

# Heading Structure

Use one H1 per page.

Follow a logical hierarchy:

H1
H2
H3
H4

Never skip heading levels unnecessarily.

---

# Content Strategy

Content should focus on helping users.

Topics include:

- Hosting guides
- WordPress tutorials
- Node.js deployment
- Python hosting
- Domain management
- Website optimization
- Student resources

---

# Internal Linking

Link naturally between:

- Product pages
- Documentation
- Blog posts
- FAQs
- Contact page

---

# Images

Every image must include:

- Descriptive filename
- ALT text
- Optimized format (WebP/AVIF)
- Lazy loading where appropriate

---

# Structured Data

Implement Schema.org where applicable:

- Organization
- Website
- Breadcrumb
- FAQ
- Article
- Product

---

# Technical SEO

Requirements:

- XML sitemap
- robots.txt
- HTTPS
- Canonical URLs
- Clean redirects
- Fast loading pages

---

# Core Web Vitals Targets

- LCP < 2.5s
- INP < 200ms
- CLS < 0.1

---

# AI Search Readiness

Content should be:

- Well structured
- Factually accurate
- Easy to quote
- Rich in headings and FAQs

Optimize for emerging AI search engines and answer engines.

---

# Success Metrics

- Organic traffic growth
- Higher keyword rankings
- Improved click-through rate
- Better Core Web Vitals
- Increased conversions from search
