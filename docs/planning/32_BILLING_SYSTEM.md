# 32_BILLING_SYSTEM

**Project:** ShrotiHost
**Document Version:** 1.0
**Status:** Draft

---

# Purpose

This document defines the billing system experience for ShrotiHost. It covers invoices, payments, subscriptions, renewals, taxation, and payment history while integrating seamlessly with WHMCS.

---

# Primary Goals

- Make billing transparent
- Simplify payments and renewals
- Reduce failed transactions
- Provide complete invoice history
- Support multiple payment methods

---

# Target Audience

- Individual customers
- Students
- Businesses
- Agencies
- Startup teams

---

# Billing Dashboard

The billing dashboard should display:

- Outstanding invoices
- Paid invoices
- Upcoming renewals
- Recent transactions
- Active subscriptions
- Available credits (future)

---

# Invoice Lifecycle

1. Invoice generated
2. Customer notified
3. Payment received
4. Invoice marked paid
5. Receipt available
6. Renewal processed (if applicable)

---

# Payment Methods

Support:

- UPI
- Credit/Debit Cards
- Net Banking
- Wallets (future)
- International cards

Display supported methods clearly before checkout.

---

# Subscription Management

Users should be able to:

- View active subscriptions
- Change billing cycle
- Upgrade plans
- Cancel auto-renew
- Renew manually

---

# Renewals

Provide:

- Renewal reminders
- Grace period (if applicable)
- Easy one-click renewal
- Multi-year renewal options

---

# Taxes

Display:

- GST (where applicable)
- TCS (export scenarios)
- Tax breakdown
- Downloadable tax invoices

---

# Promotions

Support:

- Coupon codes
- Student discounts
- Startup promotions
- Seasonal offers

Clearly show savings before payment.

---

# Failed Payments

If a payment fails:

- Explain the reason when available
- Allow retry
- Offer alternate payment methods
- Notify the customer

---

# Transaction History

Include:

- Date
- Amount
- Payment method
- Invoice reference
- Status
- Download receipt

---

# Security

Implement:

- Secure payment gateways
- PCI-compliant integrations
- HTTPS everywhere
- Fraud monitoring (future)

---

# Accessibility

Support:

- Keyboard navigation
- Screen readers
- High-contrast themes
- Responsive layouts

---

# Analytics

Track:

- Payment success rate
- Failed payments
- Renewal rate
- Coupon usage
- Average order value

---

# Success Metrics

- Higher payment completion
- Reduced failed transactions
- Improved renewals
- Lower billing-related support requests

---

# Acceptance Checklist

The billing system should:

- Be easy to understand
- Support multiple payment methods
- Display accurate invoices and taxes
- Integrate with WHMCS
- Follow the ShrotiHost design system
