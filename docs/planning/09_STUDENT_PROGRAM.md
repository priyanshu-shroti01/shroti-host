# Purpose

This document defines the ShrotiHost Student Program.

The program exists to help students, learners, and aspiring developers launch projects without worrying about hosting costs.

---

# Vision

Every student should be able to publish a portfolio, college project, hackathon submission, or startup idea using professional hosting.

---

# Objectives

- Lower the entry barrier.
- Encourage learning.
- Build long-term customer relationships.
- Support innovation.
- Create a strong student community.

---

# Target Audience

- College students
- University students
- Coding bootcamp learners
- Hackathon participants
- Open-source contributors

---

# Eligibility

One or more of the following:

- Valid college ID
- University email address
- GitHub Student Developer Pack (future)
- Manual verification (optional)

---

# Benefits

- Student-only pricing
- Free SSL
- Free migration
- Portfolio hosting
- Daily backups
- LiteSpeed
- AI Hosting Advisor
- Launch subdomain
- Documentation & tutorials

---

# Launch Subdomain

Students may launch immediately using a free Shroti subdomain.

Example:

student.example.shroti

A custom domain can be connected later without migration.

---

# Student Journey

1. Visit Student Program page.
2. Verify eligibility.
3. Select Student Plan.
4. Complete checkout.
5. Receive hosting instantly.
6. Launch website.
7. Upgrade anytime.
